Задача: проверь НАБОР требований целиком по ISO/IEC/IEEE 29148:2018, п. 5.2.6 и
IEEE 830-1998, п. 4.3:

- set_consistent — противоречия между требованиями, между разделами, между частями документа
  (например, функциональные требования против критериев приёмки, основная часть против
  дочерней спецификации API, цели против нефункциональных требований);
- set_complete — пропущенное поведение: ошибки, граничные случаи, повторы, откаты,
  отсутствующие методы и сценарии, на которые ссылается документ;
- set_feasible — набор в целом выполним;
- set_comprehensible — набор понятен целевой аудитории (термины определены);
- set_validatable — можно подтвердить, что набор удовлетворяет бизнес-потребности;
- traceable / modifiable / ranked — трассируемость, версионность, приоритеты (IEEE 830).

Ищи в первую очередь противоречия и пропуски, которые не видны при проверке требований по
одному. Для противоречия приводи ОБЕ цитаты. В requirement_ids перечисли все затронутые
требования из списка.
